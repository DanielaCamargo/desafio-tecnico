1º clone github 

2º realizar comandos

3º criar o arquivo .env igual ao arquivo .env.example (Configurar as informações do banco mysql)

4º composer install 

5º php artisan key:generate

6º npm install

7º php artisan migrate

8º php artisan db:seed

# Rodar o projeto
- npm run dev
- php artisan serve
